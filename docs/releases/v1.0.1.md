Hardening release.

- The WebDAV reply reader now parses in a single linear pass and decodes XML entities exactly once,
  so a misbehaving or hostile server cannot stall sync or smuggle characters through
  double-decoding. Found by CodeQL.
- The desktop app's Settings page shows the real app version.

Desktop apps installed from 1.0.0 offer this update in-app. For the browser extension, replace the
unpacked folder with the new `scytale-1.0.1-chrome.zip` contents and click the reload icon on the
extensions page; your vault stays in place.
