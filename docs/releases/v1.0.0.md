The first release of Scytale: a free, open-source password manager with no server.

**Install:** see the [README](https://github.com/abdvlrqhman/Scytale#install). For Brave, Chrome, Edge,
Opera and Vivaldi, download `scytale-1.0.0-chrome.zip`, unzip it, and use **Load unpacked** on the
extensions page with Developer mode on.

### What's in 1.0

- **Browser extension** for Chromium browsers and Firefox: fill logins from the toolbar or with
  Ctrl+Shift+L, search, add and edit items, one-time codes, password generator, import and export.
- **Desktop app** for Windows, macOS and Linux: custom window, lives in the tray, can start at sign-in,
  Secret Key kept in the OS keychain, updates signed and checked in-app.
- **Sync through your own storage:** WebDAV (Nextcloud and others) in both apps, any synced folder on
  desktop. Dropbox is built in and turns on with a Dropbox app key.
- **Security:** master password plus a 128-bit Secret Key, Argon2id, XChaCha20-Poly1305, one
  encrypted file per device, rollback protection, anti-phishing fill rules, no host permissions at
  install.

### Verify your download

`SHA256SUMS.txt` is attached, and every file has signed build provenance:
`gh attestation verify <file> --repo abdvlrqhman/Scytale`.

### Known limits

- Not independently audited yet.
- Windows installers are not code-signed and the macOS app is not notarized yet; see the README for
  the first-launch steps.
- Google Drive and OneDrive sync are not in this release.
